# Code of Conduct

Personal AI OS is an open-source project for people who want to build, test, document, and improve a privacy-conscious personal AI workspace.

## Expected behavior

Contributors and maintainers should:

- discuss technical disagreements with evidence and specific examples;
- keep reviews focused on code, behavior, documentation, security, and user impact;
- welcome reproducible bug reports, usability feedback, and focused contributions from newcomers;
- protect private user data and never ask contributors to publish credentials, private conversations, runtime databases, logs containing secrets, uploads, backups, or private project artifacts;
- clearly distinguish real user feedback from synthetic fixtures, demonstrations, or maintainer-created test data;
- disclose relevant security or privacy concerns instead of hiding them to make a change appear release-ready.

## Unacceptable behavior

Harassment, personal attacks, discriminatory conduct, deliberate disruption, credential theft, secret disclosure, spam, fabricated adoption signals, and knowingly misleading security or release claims are not acceptable.

## Enforcement

Maintainers may edit, hide, lock, or remove content that violates this policy and may restrict participation when necessary to protect contributors, users, or project integrity.

Security-sensitive reports should follow `SECURITY.md` rather than being posted publicly.

## Scope

This policy applies to project repositories, issues, pull requests, reviews, and other project-managed collaboration spaces.
