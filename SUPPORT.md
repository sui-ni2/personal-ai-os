# Support

Personal AI OS is an early open-source project. Support is provided through public GitHub workflows so fixes and decisions remain visible to other users.

## Where to ask

- Reproducible software problem: open a Bug report.
- Fresh-install or first-run feedback: use Issue #7.
- Newcomer Windows no-key validation: see Issue #15.
- Feature proposal: use the Feature request form.
- Security or credential exposure: follow `SECURITY.md` and do not post sensitive details in a public issue.

## Before reporting a problem

Please include the smallest useful reproduction, operating system, relevant Python/Node/pnpm versions, and the commit or version you tested. Sanitize screenshots and logs.

Never publish API keys, `.env` contents, authorization headers, cookies, private conversations, runtime databases, logs containing secrets, uploads, backups, or private project data.

## API keys and provider accounts

The project does not provide OpenAI or Anthropic credentials, credits, subscriptions, or account support. The no-key readiness path can be tested without a paid provider account; real-provider chat requires a credential owned and controlled by the tester.

## Maintainer response model

Reports are triaged by reproducibility, security/privacy impact, user impact, and release relevance. A report may be closed when it cannot be reproduced, is out of project scope, duplicates existing work, or requires private data that cannot be safely shared.
