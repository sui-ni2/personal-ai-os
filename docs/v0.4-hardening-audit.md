# v0.4 consolidation and hardening audit

**Audit date:** 2026-08-31
**Baseline:** `origin/main` `0c509d1` (`v0.3.0-3-g0c509d1`)
**Scope:** harden the already-added continuity, governance, distribution, and
support capabilities. This audit does not add providers, cloud services, voice
features, plugins, or a second product.

## Evidence levels

- `IMPLEMENTED_UNVERIFIED` — code exists but no focused proof has run.
- `LOCALLY_VERIFIED` — deterministic local checks passed.
- `REMOTELY_VERIFIED` — exact commit SHA has completed the required remote gate.
- `FAILURE_TESTED` — a relevant failure mode is intentionally injected and checked.
- `E2E_VERIFIED` — a full user-visible path has run in a real browser or runtime.
- `BLOCKED_EXTERNAL` — only an unavailable external dependency prevents this specific proof.

## Initial findings and repairs

1. Migrations 6/7 previously used script execution without a single migration
   transaction receipt. Migration 8 changes the runner to execute every SQL
   statement inside `BEGIN IMMEDIATE`, write the receipt in the same transaction,
   retain a pre-migration backup, and refuse partial schemas rather than guess.
2. A budget preflight could let two simultaneous requests both pass. Migration 8
   adds bounded reservations; reservation and hard-limit checks share one SQLite
   writer transaction.
3. Tool confirmation was tenant/project/tool/hash/TTL/single-use bound but not
   actor-bound and consumption used a read-then-write sequence. It is now actor
   bound and consumed by one conditional update.
4. Send-scope preview accepted a conversation before proving it belonged to the
   requested project. The preview now rejects that mutation before constructing
   any scope.
5. Windows package verification assumed `Get-FileHash`; a .NET SHA-256 fallback
   now keeps CheckOnly functional on compatible older PowerShell hosts.
6. The new browser gate exposed a pnpm v11 lock-graph incompatibility around
   Playwright's optional macOS watcher. The workspace now explicitly converges
   that optional dependency to the already locked 2.3.3 release, preserving
   frozen installation and supply-chain verification.
